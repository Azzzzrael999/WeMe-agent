# 会议改期、取消与缺席规则

## 适用范围

本规则适用于已确认会议的改期、取消、迟到、无人使用和爽约处理，也适用于 Agent 发起的变更。时间使用 Asia/Shanghai、ISO 8601 带偏移时间和 `[start,end)`。只有状态为 `CONFIRMED` 的正式会议可以被改期或取消；`DRAFT` 不占用房间，`CANCELLED` 不得继续修改。

## 规则正文

### 改期和取消确认

1. 适用对象：会议组织者和 Agent。触发条件：请求改变时间、房间、参会者或取消会议。允许行为：系统必须先展示目标会议或变更前后草案，包含会议标识、时间、房间、参会者和影响；用户可以 ACCEPT、EDIT 或 REJECT。禁止行为：Agent 不得在展示草案前改变正式会议。处理结果：未确认时正式会议保持原状态和原占用。
2. 适用对象：所有确认操作。触发条件：用户选择 ACCEPT、EDIT 或 REJECT。允许行为：ACCEPT 按当前草案提交；EDIT 修改字段后让系统重新查询事实、重新校验硬约束并生成新草案；REJECT 使当前草案失效。禁止行为：不得复用 EDIT 前的确认令牌、不得跳过重新校验。处理结果：ACCEPT 成功才改变业务；EDIT 产生新令牌；REJECT 不产生业务副作用。
3. 适用对象：持有确认令牌的用户。触发条件：令牌已过期、已使用、被 EDIT 作废、目标会议已取消或版本已变化。允许行为：重新打开目标会议并生成新草案。禁止行为：不得重放旧令牌。处理结果：系统返回稳定的令牌失效或会议状态错误。

### 取消提前时间和临时取消

普通会议原则上应在开始前 30 分钟完成取消；开始前不足 30 分钟的取消属于临时取消，组织者仍可以提交，但必须说明原因并接受系统记录。会议开始后不得通过普通取消接口回溯取消；组织者只能向管理员报告实际未使用情况。客户、董事会、培训和保密会议的专项规则可以要求更长提前时间，专项规则优先于通用规则。

适用对象是组织者；触发条件是距离开始时间小于 30 分钟或已经开始；允许行为是开始前临时取消并填写原因、开始后报告缺席；禁止行为是把报告缺席当作事后修改正式状态；例外是管理员因安全事件封闭房间；处理结果是系统按取消确认、异常记录或管理员处置分别保存，不自动改写历史。

### 迟到、无人使用和爽约

组织者或参会者迟到不延长会议结束时间。开始后 10 分钟内无人签到时，管理员可以联系组织者并记录“无人使用观察”，但不得仅凭观察自动取消。确认会议无人使用且组织者明确取消后，房间从取消生效时点后的可用槽位释放。重复爽约可以由管理员依据可验证记录限制相关人员的热门时段预约资格；限制必须写明原因、范围和解除时间，不得处罚无关人员。

### 变更前后核对清单

提交改期或取消前，组织者必须核对目标会议编号、当前状态、会议版本、组织者权限和目标动作。改期草案必须同时展示 Before 与 After 的日期、时段、房间、容量、设备、必需参会者和访客影响；取消预览必须展示被取消的会议、释放的房间和可能失效的外部安排。允许行为是发现错误后选择 EDIT 或 REJECT；禁止行为是只凭会议标题、口头描述或旧截图确认。处理结果是匹配多个会议时先澄清，目标不存在或已取消时不得继续写入。

### 变更失败后的处理

如果改期确认因为房间、参会者或唯一槽位冲突失败，原会议必须继续保持 `CONFIRMED`，不得先取消再寻找新房间。适用对象是组织者和 Agent；触发条件是 Java 校验返回冲突或热门预约最终失败；允许行为是读取最新事实、排除失败候选并生成新的变更草案；禁止行为是重复提交相同旧参数、复用旧令牌或把冲突解释为改期成功；处理结果是用户收到新的候选或明确无解说明，仍需再次 ACCEPT。取消确认若因会议状态变化失败，系统应返回当前状态并要求用户重新查询。

## 例外与冲突处理

安全、设备故障或房间维护可以由管理员先封闭房间，但管理员不得直接把原会议改到其他房间；组织者必须收到替代候选并重新确认。专项会议规则优先于通用取消提前时间。系统当前不支持真实邮件通知，不得把站内记录描述为邮件已发送。任何 Agent 创建、改期、取消都必须经过人工确认；手动页面提交可以不经过 LangGraph，但必须复用相同 Java 校验和事务服务。

## 常见问题

### EDIT 后为什么要重新校验？

因为时间、房间或参会者变化可能产生新的冲突，旧草案和旧令牌不再代表当前事实。

### REJECT 会取消原会议吗？

不会。REJECT 只使变更草案失效，原确认会议保持不变。

### 已取消会议能恢复吗？

不能直接修改或恢复。需要重新创建一场新会议，并重新校验和确认。

### 迟到是否可以自动延长？

不可以。结束时间固定，延长需要重新预约后续槽位。

### 旧确认令牌还能重试吗？

不能。过期、使用过或被 EDIT 作废的令牌必须重新生成。
