# 设备故障、房间维护与应急处理 FAQ

## 适用范围

本 FAQ 适用于会议室维护、设备故障、容量或设备信息错误、预约冲突、改期、取消和知识库检索不到依据的场景。时间统一使用 Asia/Shanghai、ISO 8601 带偏移时间、`[start,end)` 和 30 分钟槽位。安全、保密和专项房型规则优先于本 FAQ。FAQ 只说明处理边界，不代表系统已经接入邮件、真实视频供应商或 IoT。

## 规则正文

### 房间维护状态

问：房间处于维护状态时可以推荐吗？

答：不可以。适用对象是 Agent、手动预约页面和管理员；触发条件是房间状态为维护、停用或现场确认存在安全故障；允许行为是排除该房间并推荐容量、时段和设备满足要求的替代房间；禁止行为是把旧缓存或目录信息当作可用事实；处理结果是新草案不得包含维护房间，管理员应记录维护开始和结束时间。

### 会前发现设备故障

问：会议开始前发现设备故障怎么办？

答：组织者必须立即通知管理员，说明房间、设备、会议编号和开始时间。可以选择同一房间的可用替代设备、满足硬约束的替代房间、取消远程或改期。替代房间必须重新查询容量、时间、设备、访客和保密条件；如果变更了草案，旧确认令牌必须失效并重新确认。不得直接进入他人已确认房间。

### 会议中途设备故障

问：会议中途发生故障怎么办？

答：主持人先暂停有风险的设备操作，改用备用文件、文字同步或不依赖设备的讨论；同时通知管理员。不得因设备故障自动延长房间占用。若必须更换房间，组织者需要结束原会议并创建新的时间和房间草案，经过人工确认；已经产生的会议历史不被覆盖。

### 容量和设备信息错误

问：房间容量或设备信息错误如何上报？

答：员工必须提供房间标识、现场观察、时间、照片或可验证描述（不含敏感内容）和影响范围给管理员。管理员核对现场后更新目录或标记维护；修正完成前，错误房间不得作为满足硬约束的候选。系统的 RAG 文档不能覆盖 Java 房间事实。

### 预约、改期和取消问题

问：预约冲突怎么办？答：系统按 MySQL 唯一约束最终裁决，失败请求可以换房间、换时间或重新求解，不能移动他人会议。问：Agent 能直接改期或取消吗？答：不能，必须先展示草案并由用户 ACCEPT；EDIT 后重新校验，REJECT 不改变正式会议。问：已取消会议能继续修改吗？答：不能，必须创建新会议。问：热门预约显示 PENDING 是成功吗？答：不是，必须等待最终业务结果。

### RAG 找不到依据

当检索结果没有能够直接支持用户问题的文档、章节和可验证内容时，Agent 必须原样回答“未找到可验证证据”，并可以请求更具体的房间、会议类型或时间条件。不得用相似标题、模型记忆或未经引用的常识补齐规则；不得把 FAQ 本身当成已经执行的业务结果。引用不足时，Policy Agent 应标记 `UNVERIFIED`，由用户或管理员提供进一步依据。

### 应急处理记录清单

管理员处理异常时必须记录发生时间、房间、会议编号、故障或安全现象、已采取的临时措施、受影响的槽位、通知对象和后续责任人。触发条件是设备故障、维护、容量错误、信息泄露、访客异常或热门预约冲突；允许行为是先保证安全、再提供替代方案并补齐记录；禁止行为是用口头消息覆盖正式状态、修改他人会议或把未验证信息写成事实；处理结果是房间或候选在事实修正前保持排除，正式改期或取消仍要经过确认。

### 信息不一致的优先级

当 RAG 文档、房间目录、现场观察和用户描述不一致时，管理员维护记录和 Java 业务事实优先于知识库中的一般说明；现场存在安全风险时先停止使用；仅有用户口述而无可验证记录时不得覆盖系统事实。适用对象是 Agent、管理员和组织者；触发条件是容量、设备、维护或会议状态出现矛盾；允许行为是标记待核验、排除风险房间并请求管理员确认；禁止行为是选择对用户最方便但未验证的答案；处理结果是回答必须说明依据来源，无法验证时返回“未找到可验证证据”。

## 例外与冲突处理

人身安全、消防、信息泄露或设备有触电风险时，任何员工都可以先停止使用并通知管理员；安全处置优先于预约便利。专项房型、客户、保密、面试和事故规则优先于本 FAQ。系统不得自动移动其他人的会议；Agent 创建、改期、取消必须人工确认。当前系统只做规则检索和 Mock 工具调用，不真正执行邮件、门禁、IoT、录制或真实视频供应商操作。

## 常见问题

### 维护房间有旧缓存时还能推荐吗？

不能。维护状态优先，旧缓存不得覆盖当前房间事实。

### 更换房间是否需要重新确认草案？

需要。任何房间或时间变化都要作废旧令牌、重新校验并再次人工确认。

### 设备坏了能否延长会议？

不能自动延长；只能使用备用方案或重新预约后续槽位。

### RAG 找不到规则时 Agent 应该怎么答？

必须回答“未找到可验证证据”，不得猜测或编造。

### 系统会自动发送故障邮件吗？

不会。当前系统不支持真实邮件发送。
